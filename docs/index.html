Vite+ Commitlint

Unified Commitlint plugin and Rust-powered CLI for the Vite+ toolchain.

QUICKSTART GUIDE VIEW SOURCE ON GITHUB ↗

ENGINEERING OVERVIEW

Ultra-fast Conventional Commits validator and Git hook integration built in Rust for the Vite+ unified frontend toolchain. Enforces semantic commit messages across local workflows and CI pipelines in microseconds.

COMMAND LINE & WORKFLOW EXAMPLES

Validate Commit Message
Validates the active git commit message against Conventional Commits specifications.
vite-plus-commitlint --edit .git/COMMIT_EDITMSG
Check Commit Range in CI
Audits entire git history range across pull requests to guarantee compliant history.
vite-plus-commitlint --from origin/main~1 --to origin/main
Vite+ CLI Plugin Task
Executes commitlint natively via the Vite+ unified task runner.
vp commitlint
